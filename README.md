# IRA Eco Life website

Static, responsive lead-generation website for IRA Eco Life — a unit of IRA Enterprises.

## Files
- `index.html`: complete website, responsive CSS, small JavaScript interactions, SEO metadata and LocalBusiness structured data.
- `assets/`: supplied owner images copied into the website.

## Preview locally
Open `index.html` in a browser. For a local server, run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Deploy
You can upload the whole folder to Netlify, or push it to a GitHub repository and import it into Vercel. Keep the `assets` folder beside `index.html`.

## Before publishing
1. Verify product availability, exact product names and environmental claims with the owner.
2. Confirm both phone numbers and the business address.
3. Replace any promotional poster images with real product photos as you take them.
4. Confirm `https://iraecolife.in/` is the intended domain and configure it at the hosting provider.
5. Add the verified company email and social links when available.
6. Set up Google Search Console and submit a sitemap after the domain is live.

The enquiry form opens WhatsApp with a prepared message; it does not store or email form submissions.
